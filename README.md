# 丧尸围城 · 第一人称射击游戏

爸爸和儿子一起做的浏览器 FPS。

**目标**：打通 9 关，从小镇尸潮一路推进到沙漠、军营和要塞，驾驶坦克与战机，最终击败第 9 关「钢铁指挥官」。开始菜单可直接选第 1～9 关；简单模式提供 2 名队友或僚机，困难模式独自作战。

## 怎么运行

使用 Node.js 22.21.0（或满足 Vite 要求的版本），在这个文件夹里打开终端，首次运行先安装依赖：

```bash
npm ci
npm run dev
```

然后浏览器打开终端里显示的地址（一般是 http://localhost:5173 ），
选择关卡和难度后，点击「开始游戏」（会锁定鼠标，按 `Esc` 解锁/暂停）。

生产构建：`npm run build`。推送 `main` 会通过 GitHub Actions 自动发布到 [在线游戏](https://andrewbaosh.github.io/deadzone/)。

首页右下角显示版本号，开发和构建时自动读取 `package.json` 的 `version`。

## 操作（快捷键参考 CS）

| 按键 | 作用 |
|---|---|
| W A S D | 移动 |
| 触摸板 / 鼠标 | 转视角 |
| 左键 / 单击 | 开火（按住连发） |
| **右键 或 F** | 开镜 / 瞄准（狙击枪放大瞄准镜） |
| **1～8** | 步枪 / 手枪 / 霰弹枪 / 火箭筒 / 狙击枪 / 加特林 / 砍刀 / 追踪导弹 |
| **Q** | 快速切回上一把枪（CS 经典） |
| Shift | 奔跑 |
| Ctrl 或 C | 蹲下 |
| 空格 | 跳跃 |
| R | 换弹 |
| **Z / X / V** | 冷冻发射器 / 冰罐 / 温感震撼弹 |
| **G** | 支援菜单；1～4 选支援，准星瞄地面，空格确认 |
| **F（坦克附近）** | 上车 / 下车；驾驶时 WASD 移动、左键开炮 |
| **M** | 背景音乐 开 / 关 |
| Esc | 暂停 / 解锁光标 |

> 没有鼠标也行：开镜可以用键盘 **F** 切换（再按一下收镜）；换枪用数字键或 **Q**。

**空战（第 8/9 关）**：鼠标转向，W/S 调油门，C 切换座舱视角。第 8 关左键机炮，长按 2 锁定、松开发射导弹；第 9 关用 1/2/3 切换机炮、反坦克导弹、空对地锁定导弹，左键开火。

简单模式下，绿色「友军 1 / 友军 2」标记的是帮助你的僚机，双方不能互相攻击。

## 上下看反了？

游戏里上下看的方向可以一键改：打开 `src/config.js`，找到
`手感.上下反转`，在 `true` / `false` 之间切一下就行（默认 `true`）。

## 给儿子：改数字就能改游戏 🎮

打开 **`src/config.js`**（玩家、基础武器、手感）或 **`src/config/gameplay.js`**（关卡、敌人、技能、支援），里面全是中文的参数，改完保存，
浏览器会自动刷新，马上看到效果。不用懂编程。

想试试看的例子：
- 觉得转视角太快 → 把 `手感.鼠标灵敏度` 从 `1.0` 改成 `0.6`
- 想跳得像超人 → 把 `PLAYER.跳跃高度` 从 `1.15` 改成 `4`
- 想要一枪一个 → 把某把枪的 `伤害` 调大，比如步枪改成 `100`
- 丧尸太多打不过来 → 把 `波次.第一波数量` 改小，或 `敌人.速度` 改慢
- 想要子弹管够 → 把枪的 `弹匣` 和 `备弹` 改大
- 火箭筒想更多发 → 改 `武器.火箭筒.弹匣`（默认 3）
- 想把丧尸震得更飞 → 调大 `武器.火箭筒.冲击力`（默认 17）
- 爆炸范围/伤害 → `武器.火箭筒.爆炸半径` / `爆炸伤害`

**火箭筒 RPG**：会飞的火箭，命中爆炸。直接砸中一只敌人有额外伤害，
爆炸把范围内的丧尸**震飞上天**。一局只有 3 发，留着被围住时用。
站太近自己也会被炸飞（可以练"火箭跳"跳上高处）。

**狙击枪 AWP**：一枪穿心、爆头必杀，射程超远。按 **右键或 F 开镜**放大瞄准，
开镜静止时指哪打哪；不开镜或移动中打得非常飘（逼你架枪瞄准）。
`config.js` 里 `武器.狙击枪`：`开镜视野`（放大倍率，越小越放大）、
`伤害`、`弹匣`、`开镜移速倍率` 都能调。

改坏了也不要紧，改回原来的数字就好。

## 文件都是干什么的

| 文件 | 作用 |
|---|---|
| `src/config.js` | 基础玩家、武器、手感参数 |
| `src/config/gameplay.js` | 关卡、敌人、载具、技能、支援参数 |
| `src/config/graphics.js` | 画质参数 |
| `src/main.js` | 主程序，把所有东西串起来 |
| `src/player.js` | 玩家的移动、跳跃、碰撞 |
| `src/weapon.js` | 枪、弹药、后坐力、换弹 |
| `src/enemy.js` | 丧尸的样子、AI、被震飞的物理 |
| `src/rocket.js` | 火箭弹（飞行、尾迹、爆炸判定） |
| `src/extraction.js` | 撤离点（光柱、光环、灯光） |
| `src/level.js` | 地图（掩体、墙、油桶） |
| `src/music.js` | 背景音乐（代码合成的电子乐） |
| `public/sounds/` | 真实枪械/爆炸音效（来源与授权见其中 CREDITS.md） |
| `src/effects.js` | 弹孔、火花、飘字特效 |
| `src/audio.js` | 音效（采样音频与代码合成） |
| `src/jet.js` / `src/groundunits.js` | 空战飞机与第 9 关地面单位 |
| `index.html` | 菜单、HUD 与样式 |

## 使用 Codex 继续开发

在 Codex 中打开仓库目录即可继续。项目约定在 [AGENTS.md](AGENTS.md)，系统和关卡详情在 [HANDOFF.md](HANDOFF.md)，历史开发记录在 [PROGRESS.md](PROGRESS.md)。原 `.claude/launch.json` 保留供 Claude Code 使用。

首次浏览器自测需要安装 Chromium：

```bash
npx playwright install chromium
```

先在一个终端运行 `npm run dev`，再在另一个终端执行：

```bash
npm run build
npm test
npm run test:menu
npm run test:regression
```

默认访问 `http://localhost:5173`，截图输出到 `test-results/`（不提交）。端口不同可设置 `URL`，例如 `URL=http://127.0.0.1:5174 npm test`。这些是启动冒烟检查，不代表所有关卡已完成回归测试；功能验证可使用 `window.__game.startAt(9, 'hard')` 等调试接口。

`test:regression` 需要 Vite 开发服务器，覆盖暂停/恢复、换弹中重开、高空弹道命中、友军标识和连续重开的资源释放。测试钩子仅在测试浏览器中注入，不进入发布产物。
