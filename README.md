# 丧尸围城 · 第一人称射击游戏

爸爸和儿子一起做的浏览器 FPS。

**目标**：撑过几波丧尸后，地图远角会升起一道**发光光柱**——那是撤离点。
杀出去、跑到光柱里**停留几秒**就撤离成功、这一局获胜。撤离点很好找：
场景里有冲天光柱，屏幕上还有个路标显示方向和距离（米）。

## 怎么运行

在这个文件夹里打开终端，运行：

```bash
npm run dev
```

然后浏览器打开终端里显示的地址（一般是 http://localhost:5173 ），
点击画面就能开始（会锁定鼠标，按 `Esc` 解锁/暂停）。

## 操作（触摸板友好，不用鼠标）

| 按键 | 作用 |
|---|---|
| W A S D | 移动 |
| 触摸板 / 鼠标 | 转视角 |
| 左键 / 单击 | 开火（按住连发） |
| **Q** | 瞄准（再按一下取消 —— 不用一直按住） |
| Shift | 奔跑 |
| Ctrl 或 C | 蹲下 |
| 空格 | 跳跃 |
| R | 换弹 |
| **E** 或 1 / 2 / 3 / 4 | 换枪（手枪 / 步枪 / 霰弹枪 / **火箭筒**） |
| **M** | 背景音乐 开 / 关 |
| Esc | 暂停 / 解锁光标 |

> 触摸板用不惯右键长按，所以瞄准改成按一下 **Q** 切换；换枪也可以按 **E** 循环，不用滚轮。

## 上下看反了？

游戏里上下看的方向可以一键改：打开 `src/config.js`，找到
`手感.上下反转`，在 `true` / `false` 之间切一下就行（默认 `true`）。

## 给儿子：改数字就能改游戏 🎮

打开 **`src/config.js`**，里面全是中文的参数，改完保存，
浏览器会自动刷新，马上看到效果。不用懂编程。

想试试看的例子：
- 觉得转视角太快 → 把 `手感.鼠标灵敏度` 从 `1.0` 改成 `0.6`
- 想跳得像超人 → 把 `PLAYER.跳跃高度` 从 `1.15` 改成 `4`
- 想要一枪一个 → 把某把枪的 `伤害` 调大，比如步枪改成 `100`
- 丧尸太多打不过来 → 把 `波次.第一波数量` 改小，或 `敌人.速度` 改慢
- 想要子弹管够 → 把枪的 `弹匣` 和 `备弹` 改大
- 想更快/更慢开启撤离 → 改 `撤离.开启波数`（默认 3 波后开）
- 觉得撤离停留太久 → 改 `撤离.停留时间`（默认 6 秒）
- 火箭筒想更多发 → 改 `武器.火箭筒.弹匣`（默认 3）
- 想把丧尸震得更飞 → 调大 `武器.火箭筒.冲击力`（默认 17）
- 爆炸范围/伤害 → `武器.火箭筒.爆炸半径` / `爆炸伤害`

**火箭筒 RPG**：会飞的火箭，命中爆炸。直接砸中一只敌人有额外伤害，
爆炸把范围内的丧尸**震飞上天**。一局只有 3 发，留着被围住时用。
站太近自己也会被炸飞（可以练"火箭跳"跳上高处）。

改坏了也不要紧，改回原来的数字就好。

## 文件都是干什么的

| 文件 | 作用 |
|---|---|
| `src/config.js` | **所有参数**（儿子主要改这里） |
| `src/main.js` | 主程序，把所有东西串起来 |
| `src/player.js` | 玩家的移动、跳跃、碰撞 |
| `src/weapon.js` | 枪、弹药、后坐力、换弹 |
| `src/enemy.js` | 丧尸的样子、AI、被震飞的物理 |
| `src/rocket.js` | 火箭弹（飞行、尾迹、爆炸判定） |
| `src/extraction.js` | 撤离点（光柱、光环、灯光） |
| `src/level.js` | 地图（掩体、墙、油桶） |
| `src/music.js` | 背景音乐（代码合成的电子乐） |
| `src/effects.js` | 弹孔、火花、飘字特效 |
| `src/audio.js` | 声音（全部代码合成，没有音频文件） |

## 接下来可以加什么

- 更多枪（狙击枪、机枪）—— 在 `config.js` 的 `武器` 里照着加一把
- 弹药箱 / 回血包掉落
- Boss 丧尸
- 排行榜、最高波数记录
- 局域网双人（这个难度大，等基础玩熟了再挑战）

想加哪个，直接跟 Claude Code 说就行。
